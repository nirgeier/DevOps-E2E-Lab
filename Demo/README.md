Module 3: Demos (~30 minutes)

In this section we will show a full demo (showcase) on what DevOps is end to end.

Scenario:	
Deploy a simple microservice (Infra, Services, Monitoring and more)
Create a Git repository with a sample application
Implement Infra using IAC tools (Creating K8s cluster for the demo)
Configure environment-specific deployments (dev, staging, prod)
Set up basic CI/CD pipeline using GitHub Actions
Pack using Docker 
Implement automated testing using AI tools (auto generated for the demo)
Prepare Helm Packages for K8s cluster
Deploy Services ArgoCD
Add Monitoring 
Simulate errors and debug few cases
Add Automation for creating tickets automatically when there is an error
